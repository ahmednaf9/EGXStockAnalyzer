# EGX Stock Analyzer

تطبيق أندرويد عربي لتحليل الأسهم المصرية اعتمادًا على ملفات الأسعار التاريخية التي يرفعها المستخدم يدويًا. لا يعتمد التطبيق على DataCedar أو أي مزود API خارجي، ولا يحتاج إلى اتصال بالإنترنت لإجراء التحليل.

## المزايا
- استيراد ملفات CSV وExcel (XLSX) من الهاتف.
- استخراج رمز السهم تلقائيًا من اسم الملف.
- التحقق من سلامة بيانات OHLCV واستبعاد الصفوف غير الصالحة والتواريخ المكررة.
- دعم تنسيقات الأرقام الشائعة بالفاصلة والنقطة.
- الشموع اليابانية مع إمكانية رسم خط اتجاه يدوي.
- RSI(14) بطريقة Wilder، ومتوسطات SMA(20/50)، وMACD مع خط الإشارة.
- ATR(14) بطريقة Wilder ونطاقات Bollinger محسوبة على آخر 20 جلسة.
- استخراج دعوم ومقاومات تقريبية من القمم والقيعان المحورية وتجميع المستويات المتقاربة.
- رصد نماذج شموع أساسية مثل دوجي ومطرقة وشهاب والابتلاع.
- مقارنة حجم آخر جلسة بمتوسط أحجام العشرين جلسة السابقة، وتقدير تدفق السيولة.
- تقييم فني نهائي متعدد العوامل: شراء قوي، شراء بحذر، محايد/انتظار، بيع بحذر، بيع قوي.
- التصنيف النهائي يجمع RSI وMACD والمتوسطات وحجم التداول والدعم والمقاومة، ولا يعتمد على مؤشر منفرد.
- لا يصدر التصنيف القوي إلا عند توافر 50 جلسة على الأقل وتأكيد الاتجاه والزخم والحجم.
- سيناريوهات سعرية قصيرة ومتوسطة وطويلة المدى ومستوى إبطال افتراضي ونسبة عائد/مخاطرة.
- زر RESET لمسح بيانات التحليل الحالية وإعادة الشاشة إلى حالتها الأولية.

## متطلبات البيانات
- يلزم 35 شمعة على الأقل لإجراء التحليل بصورة أفضل.
- يلزم 50 جلسة على الأقل لإظهار SMA 50 وإتاحة التصنيف القوي.
- الأعمدة المطلوبة: Date, Open, High, Low, Close, Volume.
- يفضّل أن تكون التواريخ بصيغة YYYY-MM-DD وأن تكون الأسعار معدلة للتجزئة والتوزيعات عند الحاجة.
- التطبيق يحلل البيانات التاريخية الموجودة في الملف فقط؛ لا يعرض أسعارًا لحظية ولا يجلب البيانات تلقائيًا.

## بناء APK
1. افتح تبويب Actions في GitHub.
2. اختر سير عمل Android APK.
3. انتظر نجاح خطوات Build debug APK وVerify APK.
4. حمّل Artifact باسم EGXStockAnalyzer-debug-apk.

## حدود مهمة
- جميع الحسابات الفنية تتم محليًا على الجهاز بعد استيراد الملف، ولا يلزم مفتاح API أو اتصال إنترنت للتحليل.
- التقييم الفني أداة فرز تعليمية مبنية على قواعد فنية تقريبية، وليس احتمالًا إحصائيًا للربح أو توصية شراء أو بيع.
- المستهدفات ووقف الخسارة سيناريوهات حسابية لا تتنبأ بالمستقبل ولا تضمن نتيجة.
- اختبر القواعد تاريخيًا وخارج العينة مع العمولات والانزلاق السعري، وراجع مصدر البيانات وجودتها قبل اتخاذ أي قرار مالي.
