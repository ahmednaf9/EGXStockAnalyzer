# EGX Stock Analyzer

تطبيق أندرويد عربي لتحليل بيانات الأسهم المصرية التاريخية من ملفات CSV.

## المزايا
- إدخال رمز التداول وإرفاق بيانات السهم التاريخية.
- فحص جودة OHLCV واستبعاد الصفوف غير الصالحة، مع دعم الفاصلة المنقوطة وعلامات الاقتباس في CSV.
- RSI(14) بطريقة Wilder، ومتوسطات SMA(20/50)، وMACD مع خط الإشارة.
- ATR(14) ونطاقات Bollinger.
- استخراج دعوم ومقاومات تقريبية من القمم والقيعان المحورية وتجميع المستويات المتقاربة.
- رصد دوجي ومطرقة وشهاب وابتلاع شرائي/بيعي محتمل.
- مقارنة حجم آخر جلسة بمتوسط أحجام العشرين جلسة السابقة.
- تقييم فني موزون من 100 نقطة، مع عرض نقاط كل محور بدل إظهار رقم مبهم.
- تصنيف الإشارات إلى إيجابي أو محايد أو سلبي؛ لا يُصنّف السهم سلبيًا بسبب انخفاض الدرجة وحده، بل يلزم توافق أكثر من مؤشر هابط.
- إظهار عدد الجلسات والتنبيه عندما تقل البيانات عن 50 جلسة أو تكون أحجام التداول غير مكتملة.
- سيناريوهات سعرية قصيرة ومتوسطة وطويلة المدى ومستوى إبطال افتراضي ونسبة عائد/مخاطرة.
- واجهة عربية للهاتف.

## بناء APK
1. افتح تبويب Actions في GitHub.
2. اختر Android APK.
3. انتظر نجاح Build debug APK وVerify APK.
4. حمّل Artifact باسم EGXStockAnalyzer-debug-apk.

## تنسيق CSV
الأعمدة بالترتيب:
Date,Open,High,Low,Close,Volume

مثال:
2026-01-05,52.10,53.00,51.80,52.75,120000

يمكن استخدام أسماء الأعمدة الإنجليزية أو العربية المدعومة في المحلل. يفضّل أن تكون التواريخ بصيغة YYYY-MM-DD وأن تكون البيانات معدلة للتجزئة والتوزيعات عند الحاجة.

## حدود مهمة
- هذه النسخة لا تتصل مباشرة بالبورصة المصرية ولا تعرض أسعارًا لحظية. الرمز وحده لا يكفي لجلب سعر حقيقي؛ يلزم مزود بيانات موثوق ومرخص وواجهة API مناسبة.
- التقييم الفني أداة فرز تعليمية مبنية على قواعد تقريبية، وليس احتمالًا إحصائيًا للربح ولا توصية شراء أو بيع.
- المستهدفات والوقف سيناريوهات حسابية لا تتنبأ بالمستقبل ولا تضمن نتيجة.
- لا تستخدم نتيجة واحدة لاتخاذ قرار مالي. اختبر القواعد تاريخيًا وخارج العينة، مع العمولات والانزلاق السعري، وراجع البيانات ومصدرها.
