# EGX Stock Analyzer

تطبيق أندرويد عربي لتحليل بيانات الأسهم المصرية من ملفات الأسعار التاريخية بصيغة CSV.

## المزايا الحالية
- إدخال كود السهم.
- استيراد CSV بأعمدة: Date,Open,High,Low,Close,Volume.
- حساب RSI(14) وSMA(20/50) وفرق EMA(12)-EMA(26) كمؤشر MACD مبسط.
- تقييم فني تجميعي من 100 نقطة يجمع الاتجاه والنماذج والزخم والسيولة والبنية السعرية والعائد إلى المخاطرة.
- مقارنة حجم آخر جلسة بمتوسط أحجام الجلسات العشرين السابقة (لا بمتوسط يتضمن الجلسة الحالية).
- عرض نسبة العائد المحتمل إلى المخاطرة عند توافر مستوى هدف ووقف قابلين للحساب.
- مستويات دعم ومقاومة تقريبية من نطاق آخر 60 جلسة.
- رصد نماذج شموع أولية: دوجي والابتلاع الشرائي/البيعي.
- سيناريوهات أهداف مبنية على متوسط المدى الحقيقي المبسط ومستوى إبطال تقريبي.
- واجهة عربية مناسبة للهاتف.

## بناء APK من GitHub
1. افتح تبويب Actions.
2. اختر Android APK.
3. اضغط Run workflow، أو انتظر تشغيله تلقائيًا بعد أي تعديل على ملفات التطبيق.
4. افتح نتيجة التشغيل الناجحة.
5. من Artifacts حمّل EGXStockAnalyzer-debug-apk.
6. فك ضغط الملف ثم ثبّت APK على هاتف أندرويد.

## تنسيق CSV
الصف الأول أسماء الأعمدة بالترتيب التالي:
Date,Open,High,Low,Close,Volume

ثم صف لكل جلسة تداول، مثل:
2026-01-05,52.10,53.00,51.80,52.75,120000

- يجب أن تكون البيانات مرتبة حسب التاريخ، وسيقوم التطبيق بترتيبها.
- استخدم أسعارًا تاريخية موثوقة ومعدلة عند الحاجة للتجزئة والتوزيعات.
- لا يوجد في هذه النسخة مزود أسعار مباشر أو API متصل بالبورصة المصرية.
- التقييم من 100 أداة فرز فني تجريبية وليس احتمالًا للربح أو توصية شراء/بيع.
- مستويات الدعم والمقاومة والنماذج والمستهدفات تقريبية وتعليمية ولا تضمن الربح أو تمثل توصية استثمارية.
- يجب اختبار أي قواعد على بيانات تاريخية خارج العينة مع احتساب العمولات والانزلاق السعري قبل استخدامها في قرارات مالية.
